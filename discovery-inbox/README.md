# 발굴 수동 수집함 (discovery-inbox)

기계 크롤이 못 뚫는 소스(펨코·인스티즈·여시 등)를 **사람이 손으로 긁어** 여기에 넣으면,
내가 읽고 **새 밈 후보**를 뽑아 정리한다.

## 넣는 법
- 커뮤니티 글·댓글을 드래그·복사해서 `.txt`/`.md` 파일로 저장.
- 파일명에 **소스와 날짜**를 넣으면 좋음. 예: `펨코_2026-07-16.txt`, `여시_유머글.md`
- 많이 넣을수록 좋음 — 여러 번 반복되는 단어라야 밈 후보로 잡힌다.
- (선택) 맨 위에 어디서 긁었는지 한 줄 적어주면 근거로 활용.

## 내가 하는 것
1. 등록된 밈은 걸러냄(이미 아는 건 후보 아님).
2. 반복되는 신조어·유행어·밈스러운 표현을 추출.
3. **후보 목록**으로 정리 → `추정 뜻 · 등장 문맥(근거) · 등장 횟수`.
4. 네가 검토 → 등록/반려. (원하면 관리자 후보 큐에 넣는 SQL도 생성)

> 원칙 그대로: 기계(+사람 수집)는 제안, 등록 결정은 사람.

## 참고
- 여기 넣은 원본 덤프 파일은 `.gitignore`로 리포에 안 올라감(용량·잡음 방지). 이 README만 추적됨.
- 파일 주면 경로만 알려줘. (예: "discovery-inbox/펨코_0716.txt 봐줘")
