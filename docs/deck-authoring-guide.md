# 덱 저작 가이드 — 주제·조건 아이디어 스펙

> "그런데이제" 밸런스게임의 주제(축)와 조건(페널티)을 만드는 법.
> 이 문서만 읽고도 바로 에펨코리아/유튜브 병맛 결의 조건을 뽑을 수 있게 쓴다.
> 정본 데이터 구조는 `src/lib/game/decks.ts`, 원석은 `docs/idea-bank.md`.

## 0. 게임이 어떻게 굴러가는가 (이걸 알아야 조건이 나옴)

- 한 덱 = **대립하는 두 선택지 A vs B**. 10판 동안 매 판 A나 B를 고른다.
- **고른 쪽에만 "그런데 이제 ___" 조건이 하나씩 누적**된다. 반대쪽은 안 건드림. 리셋 없음.
- 조건 강도 = 판 번호(2~10판). 즉 각 편은 **강도 2→10 순서로 9개 조건**을 가진다(1판은 맨몸).
- 플레이어는 "이만큼 나빠져도 그래도 이쪽?"을 계속 저울질한다. 그게 재미.
- 렌더는 `그런데 이제 {조건}.` → 조건 문구는 이 틀에 자연스럽게 붙어야 함.

**따라서 조건 = "그 선택지를 고수할 때 갈수록 나빠지는 대가"를 강도순 9개.**

## 1. 주제(축) 고르는 법

- **둘 다 매력적이면서 둘 다 저주받은** 두 선택지. 한쪽이 명백히 우세하면 노잼.
  - 좋음: 백수(자유↔가난) vs 직장인(돈↔삶없음) — 팽팽.
  - 나쁨: 1억 vs 10억 — 고민할 게 없음.
- **좌우 대칭**: 두 편이 서로 정반대 극단이어야 저울질이 팽팽해짐.
  - 더러움 vs 강박 / 도망 vs 싸움 / 두통 vs 치통.
- 축 자체가 이미 웃기거나(똥맛 카레 vs 카레맛 똥), 누구나 아는 국룰 떡밥(백수 vs 직장인)일 것.

## 2. 조건 짜는 법 — 핵심 6원칙

### ① 에스컬레이션 (mild → 나락)
강도 2는 가벼운 짜증/현타, 강도 10은 **인생 나락 or 평생 확정**. 순서대로 세진다.
- 백수: (약)"취준 중" 프사 못 내림 → (중)명절 사촌한테 세뱃돈 받음 → (강)결혼도 처가에 얹혀 기 못 폄.
- 마지막(강도 10)은 보통 **"평생 ~해야 함 / 정년까지 ~"** 같은 확정 도장.

### ② 구체적이고 생생하게 (제네릭 금지)
추상적 착한 말은 전부 노잼. **오짓하게 구체적인 상황·수치·고유명사**로.
- 노잼: "갖고 싶은 건 다 참아야 함"
- 살아남: "쿠팡 장바구니만 채우고 결제는 3개월째 못 눌러야 함"
- 노잼: "돈은 있지만 시간이 없음"
- 살아남: "월요일 아침마다 지하철 샌드위치여야 함"

### ③ 결(register) = 에펨코리아/유튜브 병맛·현타·자학
수치심·현타·나락·웃픔이 핵심 정서. 인터넷 밈 어휘 허용(현타, 나락, 광탈, 존버, 런, 사축, 리액션봇, 순삭). 착하고 교훈적이면 실패.
- "부모님이 '옆집 아들은 대기업 갔대'를 매일 브리핑해야 함"
- "상사 아재개그의 전담 리액션봇이어야 함"

### ④ 동시 성립 (한 세계로 말이 됨)
9개 조건이 **동시에 다 참일 때 하나의 일관된 세계**여야 함. 서로 모순되면 안 됨.
- 순간이동 저주: 알몸으로 + 소지품 없이 + 하루 3번 + 벽에 겹침 → 한 세계로 성립 ✓

### ⑤ 컨셉 정합성 (그 편의 전제를 배신하지 마라)
그 선택지의 핵심 컨셉과 어긋나는 조건은 빼라.
- 직장인 = "돈 많이 줌"이 컨셉 → "연봉협상서 회사가 어려워서 소리 들음"은 **모순**(돈 컨셉 배신) → 탈락.
- 대신 "돈은 넘치는데 아내가 쇼핑중독임(감당은 됨)"처럼 **돈은 있다는 전제 위**의 대가로.

### ⑥ 반전 한 방 (선택)
가끔 조건에 반전을 넣으면 고급짐.
- "그런데 이제 아내가 쇼핑중독임. 근데 이제 감당은 됨." ← 앞은 저주, 뒤는 '그래도 돈은 있으니까' 플렉스. 이게 직장인 컨셉을 오히려 강화.

## 3. 말투(음슴체) 규칙 — 렌더 틀 `그런데 이제 ___.`

- 기본 종결 = **음슴체**: `~함 / ~임 / ~됨 / ~못 봄 / ~와야 함`.
- **감수·의무형**(내가 견뎌야 하는 것) = `~해야 함` / `~어야 함`.
  - "며칠씩 쫄쫄 굶어야 함", "정년까지 굴러야 함"
- **나도 모르게 벌어지는 것**(불수의) = 서술 그대로: "토함", "알몸임", "좀비 침이 튐".
- **짧고 펀치 있게**가 유튜브 결. 길어지면 힘 빠짐. (인물형만 긴 에피소드 허용)
- ~해도/~하지만 같은 **양보형 종결은 쓰지 않는다**(옛 버전 실수).

## 4. 유형(DeckType)별 톤

| 유형 | 조건의 성격 | 문체 | 예 |
|---|---|---|---|
| attribute(속성) | 환경·신체 상태를 견딤 | 짧게 | 여름/겨울, 두통/치통, 똥맛카레 |
| person(인물) | 같이 사는 상대의 행동 | **긴 에피소드** | 얼굴천재/개그천재, 털털이/결벽러 |
| scenario(상황) | 그 행동을 고수한 대가 | 중간(≤25자) | 좀비 도망/싸움 |
| acquisition(획득) | 능력의 부작용·제약 | 짧게(≤20자) | 비행/순간이동, 저주받은 초능력 |
| value(가치) | 인생 선택의 기회비용 | 짧~중간 | 백수/직장인 |

- 인물형은 "상대가 X함"이라 `~함/~임` 서술이 자연스럽고, 다른 유형은 "내가 X해야 함"이 많음.
- 상황형은 스위치가 '포기'가 아니라 '전략 전환'으로 해석됨(결과 로직이 다름).

## 5. 가드레일 (반드시)

- **취함**: 병맛, 더러움(gross), 민망, 현타, 자학, 성인 유머 수위.
- **뺌**: 노골적 성행위(하드 19금), 혐오·차별, 미성년, 실제 폭력 미화, 진짜 욕설.
  - "개-", "존버", "런", "나락"은 밈 어휘라 OK. 성기/성행위 직접 묘사는 아웃.

## 6. 나쁜 예 → 좋은 예 (이 프로젝트 실제 반복에서)

| 노잼(before) | 병맛/현타(after) |
|---|---|
| 통장이 늘 간당간당해야 함 | (삭제) OTT 구독은 이제 못 봄 |
| 갖고 싶은 건 다 참아야 함 | 쿠팡 장바구니만 채우고 결제는 못 눌러야 함 |
| 부모님 눈치를 봐야 함 | 명절엔 사촌 동생한테 세뱃돈을 받아야 함 |
| 미래 계획을 미뤄야 함 | 결혼도 처가에 얹혀 기 못 펴고 살아야 함 |
| 이불 밖은 금지임 | 이불 속에만 있어야 함 |
| 사흘째 굶어 헛것이 보임 | 며칠씩 쫄쫄 굶어야 함 |

## 7. 조건 1세트 뽑는 체크리스트

1. 두 편이 **팽팽한 정반대 극단**인가?
2. 각 편 **9개**, 강도 2→10 **에스컬레이션**(마지막은 평생/확정 도장)?
3. 전부 **구체적·생생**한가? 착한 제네릭 문장 섞이지 않았나?
4. 결이 **에펨/유튜브 병맛·현타·자학**인가? (읽고 피식 or 현타 오나)
5. 9개가 **동시 성립**하는 한 세계인가?
6. 그 편의 **컨셉을 배신하는 조건**은 없나?
7. **음슴체**(~함/~임/해야 함), 양보형(~해도) 안 썼나?
8. **가드레일** 통과(성묘사·혐오·미성년 배제)?
9. 좌우 편 **강도가 대칭**이라 어느 쪽도 명백히 낫지 않나?
