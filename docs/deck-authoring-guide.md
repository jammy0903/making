콜. 처음부터 끝까지 다른 세션 AI가 이 문서 하나만 읽고 바로 조건 뽑을 수 있게 다시 씀. 지금까지 반복에서 나온 실수·교정까지 다 녹임.

# 덱 저작 프롬프트 — "그런데 이제" 밸런스게임 주제·조건 창작 가이드

## 0. 게임 구조 (이걸 모르면 조건이 안 나옴)

- 한 덱 = **팽팽하게 대립하는 두 선택지 A vs B**
- 플레이어는 10판 동안 매 판 A나 B 중 하나를 고름
- **고른 쪽에만** "그런데 이제 ___" 조건이 하나씩 누적됨. 반대쪽은 건드리지 않음. 리셋 없음
- 조건 강도 = 판 번호(2~10판). 각 편은 **강도 2→10 순서로 9개 조건**을 가짐(1판은 맨몸)
- 렌더 틀: `그런데 이제 {조건}.` — 조건 문구는 이 틀에 자연스럽게 붙어야 함

즉 조건 = **그 선택지를 고수할 때 갈수록 나빠지는 대가**를 강도순 9개.

## 1. 주제(축) 잡는 법

### 원칙 1 — 둘 다 매력적이면서 둘 다 저주받아야 함
한쪽이 명백히 우세하면 게임이 안 굴러감.
- ✅ 백수(자유↔가난) vs 직장인(돈↔삶없음) — 팽팽
- ❌ 1억 vs 10억 — 고민할 게 없음

### 원칙 2 — 좌우가 정반대 극단이어야 함
- 더러움 vs 강박 / 도망 vs 싸움 / 두통 vs 치통 / 남 속마음 듣기 vs 내 속마음 들키기

### 원칙 3 — 축 자체가 이미 웃기거나 국룰 떡밥일 것
- 똥맛 카레 vs 카레맛 똥 / 백수 vs 직장인 / 카톡 3초컷 애인 vs 카톡 3일컷 애인

### 원칙 4 — 상식적으로 한쪽이 더 나빠 보이면, 그쪽 조건을 더 악랄하게
축 자체가 완벽히 대칭이 아닐 때(예: "남 속마음 듣기 vs 내 속마음 들키기"는 상식적으로 후자가 더 지옥) **조건 강도로 대칭을 맞춰야 함**. 원래 덜 나빠 보이는 쪽 조건을 더 악랄하게 짜서 저울질이 성립하게 만듦.

## 2. 조건 짜는 법 — 핵심 원칙

### ① 자동성 금지, 강제성만 (★가장 중요★)

**축 자체에 딸려오는 기본 사양은 조건이 아님.** 그걸 조건으로 쓰면 축을 반복한 것뿐.

- **자동성** = 축의 기본값이 그냥 발동됨. 내가 참거나 감수할 여지 없음 → **조건으로 쓰면 안 됨**
- **강제성** = 그 기본 사양을 쥐고 살면서 **내가 감수하거나 지켜야 하는 추가 룰/제약/의무** → **조건 = 이것**

**"여름" 축 예시로 감 잡기**:
- ❌ 자동성: "그런데 이제 더움" (여름이면 당연히 더움 = 축 반복)
- ❌ 자동성: "그런데 이제 땀이 남" (여름이면 자동으로 남)
- ✅ 강제성(감수형): "그런데 이제 찬물 샤워만 해야 함"
- ✅ 강제성(의무형): "그런데 이제 에어컨 켜면 벌금 냄"

강제성은 두 결로 나뉨:
1. **감수형** = 기본 사양의 불편을 완화 없이 감수해야 하는 룰
   - 여름 → "선풍기도 못 켬"
   - 짠맛 → "물도 못 마시고 참아야 함"
2. **의무형** = 기본 사양 때문에 추가로 해야 하는 행동
   - 여름 → "매일 얼음 20kg 사서 방에 쌓아야 함"
   - 짠맛 → "외식마다 짠 티 안 내려고 물 3잔 원샷해야 함"

### ② 연결성 필수 — 뜬금없는 룰 금지

강제성 조건이라도 **축의 컨셉에서 자연스럽게 유도되는 룰**이어야 함. 뜬금없는 페널티 붙이면 "이게 왜 나옴?" 됨.

- 남 속마음 듣기 축:
  - ❌ 연결성 없음: "매일 밤 노트에 손글씨로 100줄 옮겨 적어야 함" (왜 노트? 왜 손글씨?)
  - ❌ 연결성 없음: "데이트 안 하면 자동 취소됨" (속마음 듣기랑 뭔 상관?)
  - ✅ 연결성 있음: "들은 험담은 24시간 안에 당사자한테 알려야 함" (알아버렸으니 처리 의무 발생 — 자연스러운 인과)

- 백수 축:
  - ❌ 연결성 없음: "매일 팔굽혀펴기 100개 해야 함"
  - ✅ 연결성 있음: "명절엔 사촌 동생한테 세뱃돈 받아야 함" (백수라서 벌어지는 굴욕)

### ③ 에스컬레이션 (mild → 나락)

강도 2는 가벼운 짜증·현타, 강도 10은 **인생 나락 or 평생 확정**. 순서대로 세짐.
- 마지막(강도 10)은 보통 **"정년까지 ~ / 임종 때까지 ~ / 죽어야 함"** 같은 확정 도장.

### ④ 구체적이고 생생하게 (제네릭 금지)

착한 추상어는 전부 노잼. **오짓하게 구체적인 상황·수치·고유명사**로.
- ❌ "갖고 싶은 건 다 참아야 함"
- ✅ "쿠팡 장바구니만 채우고 결제는 3개월째 못 눌러야 함"
- ❌ "돈은 있지만 시간이 없음"
- ✅ "월요일 아침마다 지하철 샌드위치여야 함"

### ⑤ 결(register) = 디시/펨코 병맛·현타·자학

수치심·현타·나락·웃픔이 핵심 정서. 인터넷 밈 어휘 적극 허용:
- 현타, 나락, 광탈, 존버, 런, 사축, 리액션봇, 순삭, 손절, 킹받네, 어쩔티비, n빵, 3분컷, 박제, 저격, ㅋㅋㅋㅋㅋ, D 박힘

착하고 교훈적이면 실패. 인사평가 D, 익명 커뮤 박제, 단톡 저격, .jpg 짤 같은 리얼한 디테일이 결을 살림.

**단, 큰따옴표 대사는 쓰지 말 것.** 대사는 서술로 녹여야 함.
- ❌ "부장이 '나 때는 말이야'라고 함"
- ✅ "부장 무용담 40분간 리액션봇 노릇 해야 함"

### ⑥ 동시 성립 (한 세계로 말이 됨)

9개 조건이 **동시에 다 참일 때 하나의 일관된 세계**여야 함. 서로 모순되면 안 됨.

### ⑦ 컨셉 정합성 (그 편의 전제를 배신하지 마라)

그 선택지의 핵심 컨셉과 어긋나는 조건은 뺌.
- 직장인 = "돈 많이 줌"이 컨셉 → "회사가 어려워서 연봉 삭감됨"은 컨셉 배신 → 탈락
- 대신 "돈은 넘치는데 아내가 쇼핑중독임" 처럼 **돈은 있다는 전제 위**의 대가로

### ⑧ 반전 한 방 (선택)

가끔 조건에 반전 넣으면 고급짐.
- "그런데 이제 아내가 쇼핑중독임. 근데 이제 감당은 됨." ← 앞은 저주, 뒤는 '그래도 돈은 있으니까' 플렉스

## 3. 말투(음슴체) 규칙 — 렌더 틀 `그런데 이제 ___.`

- 기본 종결 = **음슴체**: `~함 / ~임 / ~됨 / ~못 봄`
- **감수·의무형**(내가 견뎌야 하는 것) = `~해야 함` / `~어야 함`
  - "며칠씩 쫄쫄 굶어야 함", "정년까지 굴러야 함"
- **나도 모르게 벌어지는 것**(불수의) = 서술 그대로: "토함", "알몸임"
- **양보형 종결(~해도/~하지만)은 쓰지 않음**
- 짧고 펀치 있게. 인물형만 긴 에피소드 허용

## 4. 유형(DeckType)별 톤

| 유형 | 조건의 성격 | 문체 | 예 |
|---|---|---|---|
| attribute(속성) | 환경·신체 상태를 견딤 | 짧게 | 여름/겨울, 두통/치통, 짠맛/밍밍맛 |
| person(인물) | 같이 지내는 상대의 행동 | **긴 에피소드 허용** | 얼굴천재/개그천재, 라떼충 부장/MZ 흉내 부장 |
| scenario(상황) | 그 행동을 고수한 대가 | 중간(≤25자) | 좀비 도망/싸움 |
| acquisition(획득) | 능력의 부작용·제약 | 짧게(≤20자) | 남 속마음 듣기/내 속마음 들키기 |
| value(가치) | 인생 선택의 기회비용 | 짧~중간 | 백수/직장인 |

- 인물형은 "상대가 X함"이라 `~함/~임` 서술이 자연스러움. 다른 유형은 "내가 X해야 함"이 많음
- 상황형은 스위치가 '포기'가 아니라 '전략 전환'으로 해석됨

## 5. 가드레일 (반드시)

- **취함**: 병맛, 더러움(gross), 민망, 현타, 자학, 성인 유머 수위
- **뺌**: 노골적 성행위(하드 19금), 혐오·차별, 미성년, 실제 폭력 미화, 진짜 욕설
- 밈 어휘("개-", "존버", "런", "나락", "새X" 정도)는 결로 OK. 성기/성행위 직접 묘사는 아웃

## 6. 나쁜 예 → 좋은 예 (실제 반복에서 나온 교정)

### 자동성 → 강제성 교정
| 자동성 (탈락) | 강제성 (교정) |
|---|---|
| 편의점 알바 속마음이 들림 | 편의점 알바한테 험담 들으면 그 편의점 다시 못 감 |
| 지하철에서 승객 전원 속마음 수신 | 지하철 탈 때마다 이어폰 볼륨 최대로 켜고 이명 감수해야 함 |
| 부장 무용담이 들려옴 | 부장 무용담 40분간 리액션봇 노릇 해야 함 |
| 생일 케이크가 소금덩어리라 억지로 웃음 | 생일마다 케이크 못 먹고 물로 목만 축여야 함 |

### 연결성 없음 → 연결성 교정
| 뜬금없음 (탈락) | 연결성 있음 (교정) |
|---|---|
| 매일 밤 노트에 손글씨 100줄 옮겨야 함 | (삭제, 축과 무관) |
| 데이트 안 하면 자동 취소됨 | (삭제, 축과 무관) |

### 제네릭 → 구체 교정
| 노잼(before) | 병맛/현타(after) |
|---|---|
| 통장이 늘 간당간당해야 함 | OTT 구독은 이제 못 봄 |
| 갖고 싶은 건 다 참아야 함 | 쿠팡 장바구니만 채우고 결제는 못 눌러야 함 |
| 부모님 눈치를 봐야 함 | 명절엔 사촌 동생한테 세뱃돈을 받아야 함 |
| 미래 계획을 미뤄야 함 | 결혼도 처가에 얹혀 기 못 펴고 살아야 함 |

## 7. 조건 1세트 뽑는 체크리스트 (모든 조건이 다 통과해야 함)

각 조건마다 다음 질문을 순서대로 던짐:

1. **자동성 검사**: "이 조건, 축의 기본 사양을 다시 말한 것뿐 아님?" → 그렇다면 탈락
2. **연결성 검사**: "이 룰이 왜 존재하는지가 축의 컨셉에서 자연스럽게 나옴?" → 아니면 탈락
3. **구체성 검사**: "제네릭한 착한 말 아님? 구체적 상황·수치·고유명사 있음?" → 없으면 탈락
4. **결 검사**: "디시/펨코 병맛·현타·자학 결임? 읽고 피식 or 현타 옴?" → 아니면 탈락
5. **컨셉 정합성 검사**: "그 편의 컨셉을 배신하지 않음?" → 배신하면 탈락
6. **음슴체 검사**: "~함/~임/~해야 함으로 끝남? 양보형(~해도) 안 씀?" → 아니면 수정
7. **대사 검사**: "큰따옴표 대사 쓰지 않음?" → 썼으면 서술로 녹임
8. **가드레일 검사**: "성묘사·혐오·미성년 없음?" → 있으면 탈락

세트 전체 검사:

9. 두 편이 **팽팽한 정반대 극단**인가?
10. 각 편 **9개**, 강도 2→10 **에스컬레이션**(마지막은 정년/평생 확정 도장)?
11. 9개가 **동시 성립하는 한 세계**인가?
12. 좌우 편 **강도가 대칭**이라 어느 쪽도 명백히 낫지 않나?
13. 축이 대칭 아닌 경우(한쪽이 원래 더 나빠 보임), **덜 나빠 보이는 쪽 조건을 더 악랄하게** 짜서 팽팽함을 맞췄나?

## 8. 창작 진행 순서 (권장)

1. 축 브레인스토밍 → 원칙 1~4 만족하는 후보 여러 개
2. 하나 골라서 **양편 컨셉 한 줄 요약** 확정 (예: A는 대인 지옥, B는 허무 지옥)
3. **컨셉 정합성 기준선** 명시 (뭘 하면 컨셉 배신인지)
4. 각 편 조건 9개 초안 뽑기
5. 각 조건에 대해 **자동성 검사 → 연결성 검사** 두 관문 우선 통과시키기
6. 그다음 구체성·결·음슴체·대사 검사로 다듬기
7. 세트 전체 검사(동시 성립·대칭·에스컬레이션)로 최종 조율
