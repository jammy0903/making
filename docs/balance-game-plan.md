## 0. 왜 검토했나 (v1 유지)

- 현재 랭킹 게임은 PIKU와 정면 경쟁 + 후보 이미지 저작권 리스크.
- 밸런스 게임은 **저작권 청정**(조건 문구는 창작), 1분·10판 바이럴 유리.
- 국내에 "조건 에스컬레이션" 방식은 아직 없음 — 신규 카테고리 각인 여지.

## 1. 3층 데이터 파이프라인 (v1 유지)

원본 데이터 하나(`판, 선택, 강도, 반응시간`)에서 세 결과가 순차적으로 나옴.

| 층 | 내용 | 데이터 필요 | 예 |
|---|---|---|---|
| 1층 · 신념의 강도 | 유저 혼자 데이터로 계산 | 0명 | "히터 고장에도 겨울 감수" |
| 2층 · 취향 프로필 | 유저 혼자 데이터로 계산 | 0명 | "초반 유연, 특정 판 완고" |
| 3층 · 남들과 비교 | 다른 유저 통계 필요 | N명 | "상위 8% 겨울 근본주의자" |

## 2. 콜드 스타트 회피 (v1 유지)

1·2층으로 결과 카드 완결 → 출시 시점 재미 확보. 3층은 데이터 쌓이면 오픈.

## 3. 게임 규칙 (코어 확정 · 일부 v2 개정)

### 3.1 조건 구조 (v2 확정 · v3.1 가변 길이 반영)
- 한 덱 = **팽팽하게 대립하는 두 편 A vs B**.
- 각 편은 **강도 2부터 순서대로 N개 조건**(N=4~9, 덱마다)을 미리 가짐. 1판은 맨몸(축만 대결).
  - **⚠️ v3.1(2026-07-12)**: 10판 고정 폐기 → **판 수 5~10, 덱마다 자유**. 마지막 강도가 그 덱의 확정 도장. 모든 덱이 강도 10까지 갈 필요 없음.
- 조건 강도 = 판 번호. 판 번호가 곧 그 조건의 "세기"임.
- 각 조건은 **자동성 금지, 강제성만**(§4 저작 원칙). 상세는 별도 저작 가이드.

### 3.2 매 판 규칙 (페널티-온리, v1 유지)
- 각 판 = **고른 쪽에만 그 판 강도의 조건이 붙는 대결**. 반대쪽은 안 건드림.
- 스위치해도 게임 계속. **쌓인 조건은 리셋 안 됨** — 양쪽 다 누적(리셋 없음).

### 3.3 스펙 축적 규칙 (v1 유지)
- **여름 고름** → 여름 편에 그 판 조건 추가 = "이 조건 감수하고 여름".
- **겨울로 스위치** → 그 순간부터 겨울 편에 조건이 붙기 시작.
- 여름에 쌓인 건 리셋 없이 보존.

### 3.4 예시 트레이스 (음슴체로 재작성 · v2)

| 판 | 여름 (쌓인 조건) | 겨울 (쌓인 조건) | 선택 | 비고 |
|---|---|---|---|---|
| 1 | 여름 | 겨울 | 여름 | 맨몸 대결 |
| 2 | + 에어컨 못 씀 | 겨울 | 여름 | 여름 감수 |
| 3 | + 에어컨 못 씀, 지하철 만원 서서 가야 함 | 겨울 | **겨울** | 🔴 임계점 |
| 4 | (여름 조건 보존) | + 히터 고장 견뎌야 함 | 겨울 | 겨울 감수 |
| 5 | (보존) | + 히터 고장, 폭설로 출근 3시간 걸려야 함 | 겨울 | 겨울 감수 |

### 3.5 스위치 처리 규칙 (v1 확정 유지)

1. **조건은 항상 "지금 고른 쪽"에만 붙는다** (적응형 충성 테스트).
2. **기록·누적 스펙은 절대 리셋 안 한다** (기록이 곧 상품).
3. **스위치 = 임계점 이벤트로 별도 포착** — `(판 번호, 강도, 카드 문구)` 저장.
4. **강도는 판 번호에 고정, 스위치로 리셋 안 됨** — 왔다갔다 악용 불가.

### 3.6 렌더링 포맷 (v2 개정 — 음슴체 병렬 나열)

**변경 이유**: v1의 `~해도/~이어도` 활용형은 저작 세션에서 확정된 조건 문법(`~해야 함 / ~함 / ~임`)과 충돌. 조건 원문을 활용 없이 그대로 실어야 하므로 렌더를 **마침표 병렬**로 변경.

**렌더 틀**: `{편 이름}. 그런데 이제 {조건1}. 그런데 이제 {조건2}. …`

예시:
- 1판 (맨몸): `여름` **vs** `겨울`
- 3판 (여름 2개 누적): `여름. 그런데 이제 에어컨 못 씀. 그런데 이제 지하철 만원 30분 서서 가야 함.` **vs** `겨울`
- 5판 (스위치 후 겨울 2개 누적): `여름. 그런데 이제 에어컨 못 씀. 그런데 이제 지하철 만원 30분 서서 가야 함.` **vs** `겨울. 그런데 이제 히터 고장 견뎌야 함. 그런데 이제 폭설로 출근 3시간 걸려야 함.`

**최종 결과 카드**: 고른 쪽의 완성된 병렬 문장 = 자기설명적 공유물.

### 3.7 결과 카드 (2-리스트 템플릿 · v2 음슴체 대응)

유형 이름 없음. 리스트 두 개로 조립. 조건 원문을 결과 카드에서 나열할 때 **명사구화**함:
- `~해야 함` → `~하기` / `~함` → `~하기` / `~임` → `~인 상태`
- 예: "에어컨 못 씀" → "에어컨 못 쓰기" / "지하철 만원 서서 가야 함" → "지하철 만원 서서 가기"

템플릿:
> 당신은 **{감수한 조건들 명사구, 쉼표 나열}에도** {최종 편}을 감수하는 타입입니다.
> 😖 **당신이 손절한 조건:** {스위치를 유발한 조건들}
> *(옵션) 같은 {최종 편}파 상위 N%* ← 3층, 데이터 쌓이면

§3.4 트레이스 적용 예:

> 당신은 **히터 고장 견디기, 폭설로 출근 3시간 걸리기에도** 겨울을 감수하는 타입입니다.
> 😖 **당신이 손절한 조건:** 지하철 만원 30분 서서 가기

- 한 번도 안 갈아탐 → "손절한 조건: 없음 (아무것도 못 흔든 근본)".
- 여러 번 갈아탐 → 손절 리스트가 길어짐 = 까다로운 사람.

### 3.8 결과 엔진 = 규칙 기반 (v1 확정 유지)

- 계산값: 선택 카운트 · 스위치 위치·횟수 · **감수 리스트** · **손절 리스트** · 임계점 · 상위 %.
- **AI는 선택적으로만**: 덱 저작 보조(오프라인), 프리미엄 심층 분석, 자유 주제. **MVP엔 불필요.**

## 4. 조건 저작 원칙 (v2 신규 — 저작 세션 반영)

> 상세 저작 가이드는 별도 문서(`docs/deck-authoring.md`)로 관리. 이 계획서엔 원칙만 요약.

### 4.1 5가지 유형(DeckType)

| 유형 | 조건 성격 | 문체 | 예 |
|---|---|---|---|
| attribute(속성) | 환경·신체 상태 감수 | 짧게 (≤15자) | 여름/겨울, 짠맛/밍밍맛 |
| person(인물) | 같이 지내는 상대의 행동 | 긴 에피소드 허용 (≤40자) | 카톡 3초컷/3일컷, 라떼충 부장/MZ 흉내 부장 |
| scenario(상황) | 그 행동을 고수한 대가 | 중간 (≤25자) | 좀비 도망/싸움 |
| acquisition(획득) | 능력의 부작용·제약 | 짧게 (≤20자) | 남 속마음 듣기/내 속마음 들키기 |
| value(가치) | 인생 선택의 기회비용 | 짧~중간 | 백수/직장인 |

### 4.2 저작 8원칙 (전 조건 통과 필수)

1. **자동성 금지**: 축의 기본 사양을 재진술한 조건은 탈락 (여름 축에 "그런데 이제 더움"은 축 반복일 뿐).
2. **강제성만**: 축의 기본 사양을 쥐고 살면서 **감수하거나 지켜야 하는 추가 룰**만 조건. "여름 + 찬물 샤워만 해야 함" ✓.
3. **연결성 필수**: 룰이 왜 존재하는지가 축의 컨셉에서 자연스럽게 유도돼야 함. 뜬금없는 페널티(예: "매일 노트 100권 채워야 함") 금지.
4. **에스컬레이션**: 강도 2 = 가벼운 짜증, 그 덱 마지막 강도(5~10) = 인생 나락·평생 확정 도장.
5. **구체·생생**: 제네릭 착한 말 금지. 오짓하게 구체적 상황·수치·고유명사 필수.
6. **결(register) = 디시/펨코 병맛·현타·자학**: 밈 어휘 허용(현타, 나락, 존버, 손절, 킹받네, 어쩔티비, 3분컷, 박제). 큰따옴표 대사는 서술로 녹임.
7. **동시 성립·컨셉 정합성**: 조건 전부(4~9개)가 한 세계로 모순 없이 성립. 편의 컨셉 배신 금지.
8. **음슴체**: `~함 / ~임 / ~해야 함`. 양보형(`~해도/~하지만`) 금지.

### 4.3 가드레일

- 취함: 병맛, 더러움, 민망, 현타, 자학, 성인 유머
- 뺌: 노골 성행위, 혐오·차별, 미성년, 실제 폭력 미화, 진짜 욕설
