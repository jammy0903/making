# "그런데 이제" — 밸런스 게임 피벗 계획

> 상태: **탐색 초안** (2026-07-09). 게임 규칙 코어는 확정(§3.5~3.7), 콘텐츠·전략은 미결.
> 랭킹 게임 → "10판 밸런스 게임 + 스펙 누적기" 피벗.
>
> **제품명 = "그런데 이제"** (2026-07-09 확정). 밈 포맷("그런데 이제 ~를 곁들인")을 게임 문장 렌더링의 정본으로 채택 — 매 선택이 이상형 문장에 `그런데 이제 ~해도`를 이어붙인다. 이름·규칙·말맛을 한 방향으로 정렬.

## 0. 왜 검토했나

- 현재 랭킹 게임은 PIKU 와 정면 경쟁 + 후보(연예인 사진) 저작권 리스크 상존.
- 밸런스 게임은 **저작권 청정**(조건 문구는 창작), 짧고(1분·10판) 바이럴에 유리.
- 국내에 "조건 에스컬레이션" 방식은 아직 없음 — 신규 카테고리로 각인 여지.

## 1. 3층 데이터 파이프라인 프레임

유저가 10판 하는 동안 기록되는 **원본 데이터는 하나**:
`(판 D, 선택 사이드, 그 판 페널티 강도, 반응시간)`.
이 원본에서 세 결과가 순차적으로 나옴.

| 층 | 내용 | 데이터 필요 | 예 |
|---|---|---|---|
| 1층 · 신념의 강도 | 유저 혼자 데이터로 계산 | 0명 | "월급 30% 삭감이어도 여름" |
| 2층 · 취향 프로필 | 유저 혼자 데이터로 계산 | 0명 | "초반 유연, 특정 판 완고" |
| 3층 · 남들과 비교 | 다른 유저 통계 필요 | N명 | "상위 8% 여름 근본주의자" |

## 2. 콜드 스타트 회피 원칙

3층(비교)이 제일 재밌지만 데이터 없으면 안 돌아감 → **초반 텅 빈 통계** = 유저 이탈.
해법: **1·2층으로 결과 카드를 완결시키고, 3층은 데이터 쌓이면 켜는 스위치**.

- 출시 시점 (유저 0명): 1·2층만으로도 공유 가능한 결과 카드 완성.
- 데이터 쌓인 후: 3층 슬며시 오픈 → 재방문 유인.

## 3. 게임 = **스펙 누적기** (핵심 재프레임)

**손절 시 종료가 아니라 10판 다 채워서 나만의 이상형 스펙을 쌓음.**

### 3.1 매 판 규칙 (페널티-온리 · 2026-07-09 확정)
- 각 판 = **고른 쪽에만 페널티가 붙는 대결.** 반대쪽은 안 건드림(보너스 없음).
  - 1판: `여름 vs 겨울` (둘 다 깨끗) → 여름 고르면
  - 2판: `여름 + 페널티 vs 겨울` — "여름이 이렇게 불리해져도 그래도 여름?"
- 매 선택 = 고른 쪽 문장에 `그런데 이제 ~해도` 하나 추가.
- 스위치해도 게임 계속. **쌓인 페널티는 리셋 안 됨** — 갈아탄 뒤에도 이전 쪽 페널티는 그대로 남고, 새로 고른 쪽에 페널티가 붙기 시작(양쪽 다 누적).

### 3.2 스펙 축적 규칙 (페널티-온리)
- **여름 고름** → 여름에 그 판 페널티 A 추가 = "A해도 여름" 감수 기록.
- 다음 판 여름 또 고르면 A' 하나 더 누적. 겨울은 그대로.
- **겨울로 스위치** → 그 순간부터 겨울에 페널티가 붙기 시작. 여름에 쌓인 건 그대로 보존(리셋 없음).
- 유혹(보너스) 개념 없음 — 반대쪽은 "지금까지 쌓인 만큼"의 상태로 대기.

### 3.3 예시 트레이스 (페널티-온리, 축약 5판)

| 판 | 여름 (쌓인 페널티) | 겨울 (쌓인 페널티) | 선택 | 비고 |
|---|---|---|---|---|
| 1 | 여름 | 겨울 | 여름 | base |
| 2 | +에어컨 없어도 | 겨울 | 여름 | 여름 감수 |
| 3 | +에어컨 없어도 +지하철 만원 서서 | 겨울 | **겨울** | 🔴 스위치 = 임계점(지하철 만원) |
| 4 | (여름 페널티 보존) | +히터 고장이어도 | 겨울 | 겨울 감수 |
| 5 | (보존) | +히터 고장 +폭설 출근 3시간 | 겨울 | 겨울 감수 |

→ 여름에 붙었던 페널티는 3판 스위치 후에도 안 지워지고 남음(리셋 없음). 갈아탄 뒤 겨울에만 새 페널티 누적.

### 3.4 결과 카드 (2-리스트 한 줄 템플릿 · 2026-07-09 확정)

유형 이름 없음. 계산 리스트 두 개로 조립:

> 당신은 **{최종 사이드에서 감수한 페널티들, "~해도" 나열}** {최종 사이드}을 좋아하는 타입입니다.
> 😖 **당신이 싫어하는 것:** {스위치를 유발한 카드들} *(붙자마자 반대편으로 갈아타게 만든 조건)*
> *(옵션) 같은 {최종 사이드}파 상위 N%* ← 3층, 데이터 쌓이면

위 §3.3 트레이스 적용 예:

> 당신은 **히터 고장이어도, 폭설로 출근 3시간이어도** 겨울을 좋아하는 타입입니다.
> 😖 **당신이 싫어하는 것:** 지하철 만원 30분 서서 가기

- 한 번도 안 갈아탐 → "싫어하는 것: 없음 (아무것도 당신을 못 흔들었다)".
- 여러 번 갈아탐 → 싫어하는 것 리스트가 길어짐 = 까다로운 사람.

### 3.5 스위치 처리 규칙 (확정 · 2026-07-09)

이전 초안이 미결로 남겼던 "스위치하면 어떻게 되나"를 아래 4개로 확정. 핵심 통찰: **스위치 = 실패가 아니라 그 사람의 손절 임계점을 드러낸 사건.** 게임이 팔아야 할 가장 값진 데이터.

1. **페널티는 항상 "지금 고른 쪽"에만 붙는다 (적응형 충성 테스트).**
   매 판 *현재 선택한 사이드*에만 페널티를 추가. 반대쪽은 안 건드림(보너스 없음). 스위치하면 **다음 판부터 페널티가 새로 고른 쪽에 붙기 시작.**
   → (구 §5 "보너스 카드 위치" 해소) 보너스 개념 폐기 — 페널티-온리로 단순화.
2. **기록·누적 스펙은 절대 리셋 안 한다 (기록이 곧 상품).**
   스위치했다 되돌아와도 이전 스펙은 남는다. 예시 트레이스대로 유지.
   → (구 §5 "스위치 후 되돌아옴" 해소) 유지 확정.
3. **스위치 = 임계점 이벤트로 별도 포착.**
   `(판 번호, 그때 강도, 카드 문구)`를 "임계점"으로 기록 → 2층 프로필의 헤드라인·결과 카드 킬링 문구.
4. **강도는 판 번호에 고정, 스위치로 리셋 안 됨.**
   페널티 강도 램프는 판 1→10 서사에 묶는다(§4.5). *어느 쪽*이 페널티냐만 규칙1로 정해지고 *얼마나 센가*는 판 번호가 정한다. → 왔다갔다 악용 불가(후반 카드는 어느 쪽이든 강함), 오실레이션 자체가 프로필로 자동 기록됨.

### 3.6 "그런데 이제" 렌더링 포맷 (확정)

같은 누적 엔진을 밈 문장으로 읽는 방식. 페널티-온리라 **고른 쪽 문장이 자라고, 반대쪽은 지금까지 쌓인 채 대기.** 스위치하면 반대쪽이 자라기 시작(양쪽 다 페널티 누적, 리셋 없음).

- 매 판 두 사이드가 각각의 "그런데 이제" 문장으로 제시:
  `여름인데 그런데 이제 에어컨 없고 그런데 이제 지하철 만원 서서` **vs** `겨울` (아직 안 골랐으면 깨끗)
- 최종 결과 카드 = 고른 쪽의 완성된 "그런데 이제" 런온 문장 (자기설명적 공유물).

### 3.7 결과 엔진 = 규칙 기반 (무-AI, 확정)

결과 카드는 전부 결정론 계산 — §1 표의 "1·2층 = 0명 필요·유저 혼자 계산"과 정합.

유형 판정표 없이 리스트 2개로 조립(§3.4).

- 계산값: 선택 카운트 · 스위치 횟수/위치(선택 배열 diff) · **감수 리스트**(최종 사이드에서 고르며 쌓인 페널티) · **싫어하는 것 리스트**(스위치 직전 그 쪽에 방금 붙었던 페널티) · 임계점(첫 스위치 판·강도·카드) · 상위 %(3층 DB 백분위).
- **AI는 선택적으로만**: (a) 덱 저작 보조(오프라인 1회성), (b) 나중 프리미엄 "AI 심층 분석", (c) 완전 자유 주제. **MVP엔 불필요.**

## 4. 파일럿 카드 덱 — 여름 vs 겨울

### 4.1 여름 페널티 (여름 골랐을수록 나빠짐)
1. 여름 (평범)
2. 에어컨 없어도
3. 지하철 만원 30분 서서 가야 해도
4. 옆자리 상사가 하루종일 창문 열어놔도
5. 취업 면접 다 여름 낮 2시여도
6. 40°C 폭염 · 습도 90% 여도
7. 애인이 나 대신 겨울 좋아해도
8. 월급 30% 삭감이어도
9. 계약 갱신 조건 = "여름에만 일해야 함" 이어도
10. 평생 여름만, 겨울 다신 못 봐도

### 4.2 겨울 페널티
1. 겨울 (평범)
2. 히터 고장이어도
3. 폭설로 출근 3시간이어도
4. 감기 2주 · 목소리 안 나와도
5. 연말 지출 폭탄이어도
6. 이별 통보를 크리스마스에 받아도
7. 시험 당일 폭설로 시험장 못 가도
8. 손·발 동상이어도
9. 계약 갱신 조건 = "겨울에만 일해야 함" 이어도
10. 평생 겨울만, 여름 다신 못 봐도

### 4.3 카드 문구 원칙 ("그런데 이제" 틀에 맞춤)
- 모든 페널티 카드는 `그런데 이제 ___` 뒤에 붙어 **"~~해도" · "~~이어도"** 로 끝남 → `그런데 이제 에어컨 없어도`.
- 후반부(6·7·9)에 관계·미래·정체성 카드 몰아넣기 (초반은 라이트하게, 후반은 킬링 포인트). 판 수 = **10판 확정.**
