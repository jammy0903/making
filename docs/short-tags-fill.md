# short 라벨 채우기 작업 (다른 AI에게 위임용)

## 이게 뭐냐
밸런스게임 "그런데이제"의 각 조건에는 **긴 문장**(게임 보드용)과 **짧은 라벨**(결과 영수증·바구니 칩용)이 있다.
지금 긴 문장은 다 있는데, **짧은 라벨이 거의 다 비어 있다.** 이 파일의 빈칸(✍️ 칸)을 전부 채우는 게 이번 작업이다.

- 라벨 종류 2개:
  - **`short`** = 페널티(💢 참은 것) 짧은 라벨
  - **`meritShort`** = 메리트(🎁 얻은 것) 짧은 라벨
- 대상 = 공개 덱 **11개 × 각 18개(양편 9강도) = 페널티 198개**. 각 페널티마다 `short` + `meritShort` 둘 다 → **총 396칸**.
- **`salary`(월200 vs 월천) 덱의 `short`은 이미 채워져 있음** → 톤·길이의 **정답 예시**로 삼아라. (단 salary도 `meritShort`은 비어 있으니 채워야 함.)

## 작성 규칙 (중요)
1. **명사구로.** 문장 종결어미(`~함`·`~음`·`~임`·`~됨`) 쓰지 마라. 라벨이지 문장이 아니다.
   - ❌ `만원 지하철에 압사당함`  → ✅ `만원 지하철 압사`
2. **길이 = 공백 포함 대략 6~13자.** 칩/영수증 한 칸에 들어가야 한다. 짧고 강할수록 좋다.
3. **`short`(페널티) = 그 조건의 핵심 고통·굴욕·현타 키워드.** 자학 개그 톤.
4. **`meritShort`(메리트) = 그 대가로 얻는 이득 키워드.** 짧게, 비꼬거나 담백하게.
5. **편 컨셉·맥락 유지.** 그 편(예: 백수/직장인, 관종/아싸)의 정체성이 드러나게.
6. **이모지 넣지 마라.** 칩 색으로 이미 구분된다.
7. **같은 덱 안에서 라벨 중복 최소화.** 강도별로 다른 키워드를 잡아라.
8. 원문에 없는 새 설정을 지어내지 마라. 문장 안의 소재로만 압축해라.

## 정답 예시 (salary 덱, `short` 기준)
| 전체 페널티 문장 | → short |
| --- | --- |
| 카톡 상태메시지 "취준 중"을 최소 10년은 올려둬야 함 | 카톡 상메 취준중 10년째 |
| 월요일은 만원 지하철에 사람이 샌드위치처럼 꽉 끼여 실려 가야 함 | 만원 지하철 압사 |
| 친구들 다 결혼하는데 축의금은 5만원만 낼 수 있어 볼 때마다 궁상맞음 | 축의금 5만원 궁상 |
| 점심을 10분 만에 흡입하고 다시 모니터 앞이어야 함 | 점심 10분컷 |

## 작성 방법
아래 각 표의 **`short ✍️`** 와 **`meritShort ✍️`** 칸(빈칸)에 라벨을 직접 채워 넣어라. 표 구조·순서·문장은 그대로 두고 빈칸만 채운다.
