# 마케팅 실행 채널 계획 (2026-07)

[marketing-analysis.md](./marketing-analysis.md)가 제품 내부(공유 루프·SEO 기반·네이밍)를
다뤘고 그 로드맵은 완료됐다. 이 문서는 그 다음 — **밖으로 알리는 채널**을 다룬다.
전제: 1인 운영, 광고 예산 0원에서 시작, 콘텐츠 소스는 이미 있는 DB(밈 1,100+ / 짤 7,200+ /
생사 투표·랭킹·연도 데이터).

## 0. 핵심 관점 — 우리는 콘텐츠 공장을 이미 갖고 있다

일반 사이드프로젝트 홍보의 병목은 "올릴 콘텐츠가 없다"인데, memedics는 반대다.
DB 자체가 매주 콘텐츠를 뽑아낼 수 있는 원천이다:

| DB 자산 | 콘텐츠 포맷 |
| --- | --- |
| 생사 투표 게이지 | "이 밈, 아직 살아있나?" 논쟁 유발형 카드 |
| 주간 랭킹 (rank_snapshots) | "이번 주 밈 순위" 정기 콘텐츠 |
| era_year (감사 완료, 정확도 확보) | "이 밈 몇 년도?" 퀴즈 / 세대 판별기 |
| 짤 7,200장 + 한국어 캡션 | 상황별 짤 모음 ("월요일 짤 10선") |
| 사망 선고(death_lifecycle) | "이번 달 사망한 밈" 부고 — 우리만 가능 |

→ 채널 전략의 뼈대는 **"DB에서 주 1~2회 콘텐츠를 자동 반쯤 뽑아 유통"**이다.

## 1. 채널별 계획 (우선순위순)

### ① 검색 마무리 — 깔아둔 SEO의 수확 확인 (비용 0, 즉시)

SSR·sitemap·/m/[id]는 이미 구현. 남은 건 운영 확인:
- [ ] Google Search Console + **네이버 서치어드바이저** 등록·사이트맵 제출 상태 확인
- [ ] "○○ 뜻" 키워드로 실제 색인·순위 표본 측정 (밈 20개 표본)
- [ ] jjal-seo-plan.md Phase 1(짤 상세 페이지) 진행 — 짤 7,200장이 각각 랜딩 페이지가 됨
- 자연 수요 = "방금 들은 밈 뜻 검색". 이 채널은 우리가 자는 동안 일한다. **최우선.**

### ② 숏폼/인스타 밈 계정 (비용 0, 주 2~3시간)

조사 결과 공통 결론: 초반 2초 후킹 + 주제 일관성 + 꾸준함이 전부.
- 계정 컨셉: "밈 생사를 판정하는 계정" — 단순 밈 리포스팅 계정과 차별화.
  포맷 예: 밈 짤 + "이거 아직 쓰면 늙은이다 vs 아니다" → 댓글 싸움 유도 → 프로필 링크로 투표 유도
- 릴스/쇼츠 소재: 연도 퀴즈("이 밈 나온 연도 맞히면 MZ"), 주간 랭킹 카운트다운
- 사이트 공유 카드(share.js 캔버스)를 인스타 포맷(1080×1350)으로 변형해 재사용
- KPI: 게시물당 프로필 방문 → 사이트 유입. 팔로워 수보다 링크 클릭.

### ③ 런칭 플랫폼 1회성 부스트 (비용 0, 반나절)

- **디스콰이엇**(한국판 Product Hunt): 메이커로그 형식으로 "밈 1,100개 생사를 측정하는
  사이트를 만들었다" — 개발 스토리 자체가 콘텐츠. 조사된 성공 패턴: 런칭 글 1회보다
  꾸준한 메이커로그가 효과적.
- **GeekNews(news.hada.io)**: 기술적 각도("pgvector로 짤 검색 만든 이야기")로 제출
- **오픈웹사이드, 사이드프로젝트 플랫폼 목록**(ahnslab.com 정리본)에 일괄 등록 — 백링크 효과 겸용
- 효과는 스파이크 후 소멸하지만, 초기 시드 유저 + 도메인 백링크가 남는다.

### ④ 데이터 저널리즘 / 언론 인용 (비용 0, 월 1회)

marketing-analysis.md의 "측정의 권위" 포지션과 직결. 우리만 가진 데이터로 보도자료성
콘텐츠를 만든다:
- "2026 상반기 사망 선고된 밈 TOP 10" (death_candidates + 투표 데이터)
- "MZ도 모르는 2010년대 밈 생존율" (era_year × 생사 투표 교차)
- 위픽레터·고구마팜·소마코 등 밈/트렌드 뉴스레터가 이런 소재를 상시 찾는다 —
  제보/기고 형태로 접촉하면 광고비 없이 인용된다. 인용 = 백링크 + 권위.

### ⑤ 커뮤니티 시딩 (비용 0, 신중하게)

- **디시인사이드는 바이럴 마케팅 반감이 매우 큼**(나무위키 문서화될 정도) — 직접 홍보 금지.
  하는 경우에도 "홍보"가 아니라 "이 밈 사망 판정 떴는데 어떻게 생각함?" 같은
  **논쟁 소재로서의 결과물**만. 들키면 역효과가 더 크다.
- 카톡 오픈채팅/디스코드: 허가받고 홍보 가능한 방이 있음(조사 확인). 밈/유행어 관련 방 위주.
- 에브리타임: 대학생 타겟 정합성 높음. 무료 시딩은 계정 문제로 어려움 —
  유료 네이티브 광고 상품이 존재(클릭률 높다는 평). **예산 생기면 1순위 유료 채널.**

### ⑥ 유료 광고 (보류)

- 검증된 오가닉 루프(②④)가 돌기 전까지 보류. 태울 돈보다 태울 콘텐츠가 먼저.
- 시작한다면: 에브리타임 네이티브 > 인스타 스폰서(공유 카드 크리에이티브 재활용) 순.

## 2. 주간 운영 루틴 (제안)

| 요일 | 작업 | 채널 |
| --- | --- | --- |
| 월 | 주간 랭킹 스냅샷 → 카드 1장 | 인스타 + 사이트 |
| 수 | 생사 논쟁 카드 1장 ("이거 아직 씀?") | 인스타 릴스 |
| 금 | 짤 모음 or 연도 퀴즈 | 인스타 + 오픈채팅 |
| 월 1회 | 데이터 리포트 (사망 밈 등) | 뉴스레터 제보 + 디스콰이엇 로그 |

## 3. 측정

- 채널별 UTM 파라미터 (`?utm_source=instagram` 등) — 현재 미부착, 콘텐츠 유통 시작 전 필수
- 주간 확인 지표: 검색 유입(서치콘솔), 인스타 프로필 클릭, 직접 유입
- 한 달 후 채널별 유입/체류로 ②~⑤ 재배분

## 4. 하지 않을 것

- 디시 직접 홍보 (역풍 리스크 > 기대 효과)
- 팔로워 구매·품앗이 (참여율 오염 → 알고리즘 불이익, 조사에서도 공통 경고)
- 오가닉 검증 전 유료 집행
