## 1. 진단 — 왜 v2는 재미가 부족한가

### 1-1. 재미는 곱셈이다

```
재미 총합 = 콘텐츠 재미 × 메커니즘 재미 × 공유 재미
```

| 층 | 정의 | v2 점수 |
|---|---|---|
| 콘텐츠 재미 | 조건 하나가 웃긴가? (병맛·현타·자학의 밀도) | **10** |
| 메커니즘 재미 | 판이 굴러가는 자체가 재밌는가? (선택의 저울질) | **0** |
| 공유 재미 | 결과를 남한테 자랑하고 싶은가? (자기 발견·사회적 통화) | **0** |

곱셈이므로 `10 × 0 × 0 = 0`. **세 층 모두 최소 5점 이상**이어야 한다. 한 층만 살려선 안 된다.

### 1-2. 메커니즘 = 0 (수학 근거)

**문제 A · 정보 엔트로피 붕괴**
밸런스게임의 재미 ∝ 판마다 발생하는 불확실성의 양.
`판별 재미 = -Σ p(선택)·log₂ p(선택)` (p = 그 선택을 할 확률)

- 이상형월드컵 32강: 매 판 p ≈ 0.5 유지 → 엔트로피 최대(1 bit/판).
- v2: 첫 판에 축이 정해지는 순간 이후 판 p ≈ 0.9+ → 엔트로피 0으로 수렴.
  - 예: 1판에 "백수" 고르면 강도 3·4·5판에서도 "백수" 확률 90%+ → 9판이 결정이 아니라 **재확인 절차**.
- **목표: 판별 엔트로피 0.7 bits/판 이상** (반대편 넘어갈 확률이 판마다 30~70% 사이에서 흔들려야 함).

**문제 B · 하강 곡선(손실 프레임)**
프로스펙트 이론: 손실은 획득보다 심리적으로 약 **2.25배** 강함(1점 손실 = 2.25점 획득).

- v2는 판이 갈수록 페널티만 누적 → 감정 곡선이 **단조 하강**.
- BuzzFeed 퀴즈 통계상 하강 감정 곡선 이탈률 = 판당 15~25% → 10판 완주율 ≈ 5~20% 예상.
- 이상형월드컵은 반대로 "좋은 것 중 더 좋은 것" **획득(상승) 곡선** → 도파민 상승 → 완주율 70%+.

### 1-3. 공유 = 0 (심리 근거)

**문제 C · 결과가 캐릭터가 아니라 숫자**
v2 결과 "백수 8:2 직장인" = 라벨이 아니라 카운트. 캐릭터가 아니라 통계.

- Jonah Berger의 *Contagious* — 공유 6트리거 중 최강 = **Social Currency**(이걸 공유하면 내가 좋아 보이는가).
- MBTI "나 INFP" → 캐릭터 라벨 → 공유됨. 이상형월드컵 "내 이상형 카리나" → 취향 표현 → 공유됨. v2 "나 백수 8:2" → 자기 자책 → 공유 안 됨.
- **핵심: 개인 자책은 공유 안 되지만, 유형 라벨은 공유된다.** 유형 뒤에 숨을 수 있어서. 자학이 캐릭터화되면 오히려 쿨해짐(MBTI 자학 밈이 안 죽는 이유).

**문제 D · 자기 발견 없음**
MBTI가 10년째 안 죽는 이유 = "몰랐던 나"를 발견하게 해서. v2는 첫 판 답으로 결과 예측 가능 → 발견·놀람·공유 없음.

## 2. 해결책

### 2-1. 조건에 메리트 결합 (→ 메커니즘·엔트로피·하강곡선 동시 해결)

**렌더 틀 변경**
- v2: `「그런데 이제 {페널티}.」`
- v3: `「그런데 이제 {페널티}. 근데 이제 {메리트}.」`

메리트가 붙으면 판마다 "그래도 이건 좋은데…" 갈등이 생겨 p가 0.5 근처로 돌아오고(엔트로피 회복), 감정 곡선의 단조 하강이 완화된다.

**메리트 작성 4대 원칙**

| # | 원칙 | ✅ | ❌ |
|---|---|---|---|
| 1 | 같은 도메인에서 **인과적으로** 연결 | 부장 → 부장의 법카 / 라벨링 강박 → 유통기한 0개 | 부장 무용담 → 갑자기 로또 / 냉장고 라벨링 → 회사 승진 |
| 2 | 페널티 감정 강도 **>** 메리트 감정 강도 (손실 2.25배 → 감정적으론 손실 우세여야) | 40분 리액션(손실) vs 오마카세 1회(이득) | 5초 눈치(손실) vs 2억 원(이득) → 이득 압도 → 저울질 실패 |
| 3 | 메리트가 **컨셉을 배신 금지** | 직장인(돈○ 시간×) → 메리트로 "법카·성과급"(돈 도메인) | 직장인 → "갑자기 여유 시간 생김"(컨셉 배신) |
| 4 | **저울질 발생** 여부 자체 검증 | "3초 이상 망설일까?" 예 → 통과 | 망설임 없음 → 재작성 |

**정량 기준: 페널티 감정 강도 ≥ 메리트 감정 강도 × 2.**

**조건 하나마다 실행하는 판정 체크리스트 (5개 전부 통과)**
- [ ] v2 원칙 8개 통과 (자동성/연결성/구체성/결/컨셉/음슴체/대사/가드 — deck-authoring §7)
- [ ] 메리트가 같은 도메인에서 인과적으로 파생됨
- [ ] 페널티 감정 강도 ≥ 메리트 감정 강도 × 2
- [ ] 메리트가 편 컨셉 배신 안 함
- [ ] 3초 저울질 발생

**결합 예시**

| 유형·강도 | v2 | v3 |
|---|---|---|
| 인물·직장인 강도5 | 부장 무용담 40분간 리액션봇 노릇 해야 함 | …해야 함. **근데 이제 부장이 감동해서 법카로 오마카세 결제함.** |
| 속성·J배우자 강도5 | 냉장고 반찬 위치 어긋나면 라벨링 재교육 30분 받아야 함 | …받아야 함. **근데 이제 유통기한 넘긴 음식 5년째 0개임.** |
| 가치·백수 강도6 | 밥상 앞에서 부모님 취업 근황 질문에 리액션봇 노릇 해야 함 | …노릇 해야 함. **근데 이제 반찬은 매번 갈비찜임.** |

### 2-2. 결과 카드 캐릭터화 (→ 공유·자기 발견 해결)

숫자 카운트를 폐기하고 **캐릭터 카드 3스텝(커뮤체·킹받게)**로 바꾼다. 톤 = 디시/에펨 하드 놀림·반말·밈체. (구 "명사구 유형명"은 폐기 — 얌전해서 안 킹받음.)

**step 1 · 놀림 헤드라인 (taunt)**
- 형식: `ㅋㅎㅋ 당신은 ~쟁이누 / ~덕후였네 / ~먹보잖아?` — 반말로 **놀리고 킹받게.** 카드에서 가장 크고 강한 줄.
- ✅ `ㅋㅎㅋ 당신은 임종각까지 릴스 켜는 관종말기누 🎬` / `ㅋㅎㅋ 당신은 3주 뒤에 택배 쌓여서 발견되는 원조 아싸잖아? 📦`
- ❌ 「자유로운 사람」(얌전)·「임종 릴스 인플루언서」(구 명사구, 안 킹받음)
- 게임에서 나온 가장 상징적인 조건 이미지 1개를 놀림 소재로.

**step 2 · 이유 = 특이 스탯 (구체 숫자 3~5개)**
- 형식 `▸ {측정 대상}: {구체 숫자}`. **형용사 아닌 명사와 숫자만.** 왜 이 판정인지 근거를 숫자로.
- ✅ `▸ 분기당 흑역사 박제: 4.2건` / `▸ 인생 총 셀카: 1,204,000장` / `▸ 팔로워 1명당 잃은 실친: 0.7명`
- ❌ "많이 힘들어함"(측정 불가) / "돈이 없음"(숫자 아님·이미 아는 정보)
- 게임에서 유저가 **실제로 버틴 조건과 연결.**

**step 3 · 예언/저주 (curse) — 문장만**
- **문장 하나만.** "예언:"·"예상 X:" 같은 접두 라벨 붙이지 않음. 사주 밈 톤·확정 도장.
- ✅ `니 장례식 실시간 동접 3만 찍는데, 화면엔 관 대신 셀카각만 잡힐 예정 🕯️` / `평생 유튜브 댓글로만 세상이랑 소통하다, 알림 끄는 순간 진짜 무인도 됨 🏝️`
- **캡처했을 때 이 한 줄이 가장 강해야 함.**

**완성 템플릿**
```
━━━━━━━━━━━━━━━━━━━━━━━━━
ㅋㅎㅋ 당신은 {놀림 헤드라인}
━━━━━━━━━━━━━━━━━━━━━━━━━
▸ {특이 스탯 1}
▸ {특이 스탯 2}
▸ {특이 스탯 3}
━━━━━━━━━━━━━━━━━━━━━━━━━
{예언/저주 문장 한 줄}
━━━━━━━━━━━━━━━━━━━━━━━━━
동일 유형 비율: 상위 {N}%
```
> 데이터 = `ResultCard { taunt, stats[], curse }` (src/lib/game/decks.ts).

**분기 로직 — 한 편에 결과 카드 2종**
- **극단 결과**: 강도 8+ 판까지 그 편 우세 → **캡처 유발도 높음.**
- **애매 결과**: 강도 5~7 사이 전환 → **"나 이 유형인 줄 몰랐네" 발견감.**
- 둘 다 필요. (편 2개 × 극단/애매 2 = 덱당 결과 카드 4종.)

## 3. v2 → v3 유지 / 수정 / 폐기

**유지** (deck-authoring-guide v2 원칙 그대로)
- 게임 기본 구조(10판, 강도 2→10 누적, 리셋 없음) · 자동성 vs 강제성 관문 · 연결성 · 구체성 · 결(병맛/현타/자학) · 음슴체 · 큰따옴표 대사 금지 · 컨셉 정합 · 가드레일 · 축 대칭(팽팽함·정반대 극단) · 에스컬레이션 2→10 · 유형별 톤(attribute/person/scenario/acquisition/value).

**수정**
- 반전 한 방(구 원칙 ⑧): **옵션 → 필수 구조.** 모든 조건이 페널티+메리트 결합 형태.
- 결과 표시: 숫자 카운트 → **유형 캐릭터 카드.**

**폐기**
- **페널티 단독 조건 구조.**

## 4. 작업 로드맵 (콘텐츠 저작 — Step 1~6)

> 새 덱을 v3로 만들 때의 순서. 원본 프롬프트(`new-ai-prompt.md`) §4를 정리.

1. **새 축 3개 후보** — v2 예시(백수/직장인·속마음·부장·J/P배우자·여름겨울·좀비 등) **전면 재사용 금지**. 각 후보 = 축 1줄 + A/B 컨셉 1줄씩 + 팽팽 이유 1줄 + DeckType. → 사용자 선택 대기.
2. **선택 축 컨셉 정합성 기준** — A/B편 매력 1줄 + 훼손 금지 리스트 3~5개씩.
3. **조건 초안 A 9 + B 9** — v3 결합 구조, 강도 2→10, **도메인 분산**(돈/관계/시간/신체/사회지위/미래/취미 중 5개 이상, 한 도메인 최대 3회), 조건마다 5항목 체크리스트 표시.
4. **흡수 관계 검사** — 강도 낮은 조건이 높은 조건에 이미 먹히면(예: "OTT 못 봄" ⊂ "인터넷 자체 못 씀") 재작성.
5. **결과 카드 4종** — A 극단/애매, B 극단/애매. §2-2 템플릿.
6. **자체 검증 리포트** — ①판별 엔트로피(판별 확률 30~70%?) ②저울질(3초?) ③캡처 유발(4종 중 몇 개?) ④자기 발견("몰랐던 나"?) 각 항목 판정 + 근거.

## 6. 코드 영향 (요약 — 상세는 impl-status §7)

- **`Penalty`에 `merit` 필드 추가** + 렌더 `그런데 이제 {text}. 근데 이제 {merit}.` (현재는 `Side.merit` 1개를 안 고른 쪽에 표시 = **v3와 다른 구조**. 전환 필요.)
- **결과 = 캐릭터 카드 생성기** — 덱마다 편·결과(극단/애매)별 유형네이밍·특이스탯·미래예언을 **저작 데이터로** 보유. 기존 `computeResult`(선호편·버틴깊이)는 어느 카드를 띄울지 고르는 **내부 신호**로만 사용.
- 엔진의 버틴깊이/오실레이션 판정은 유지하되 **표면 문안은 캐릭터 카드로 대체.**
